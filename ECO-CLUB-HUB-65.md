# Eco Club HUB 6.5 — Центр задач руководителя

**Статус:** обновлены исходники в GitHub. Для использования в закрытой панели необходимо вручную обновить **существующее** развёртывание Google Apps Script проекта `Eco Club — Passport Admin`. Реальные заявки, вклады, мероприятия, участники и коды не менялись во время разработки.

## Что появилось

Главная вкладка «Обзор» начинается с **Центра задач руководителя**. Он объединяет данные из действующих листов двух подключённых таблиц:

- **Заявки**: новые заявки на вступление и ранее принятые заявки, для которых пока не создан постоянный ID.
- **Вклады**: ожидающие подтверждения и уже подтверждённые записи без привязки к ID.
- **Мероприятия**: публикации педагогов, ожидающие модерации.
- **Паспорта**: учащиеся без активного личного кода, просроченные коды, коды с некорректной датой, истекающие в ближайшие 7/30 дней и старые коды без срока.

На главной странице есть четыре счётчика (новые заявки, вклады на проверке, публикации на модерации, паспорта/качество данных), вкладки-фильтры **Все / Срочные / Заявки / Вклады / Мероприятия / Паспорта / Данные**, кнопка «Обновить задачи» и список задач.

Задачи сортируются по приоритету: сначала критические проблемы доступа и коды на грани истечения, затем запросы на рассмотрение, затем привязка данных и плановая работа. Показываются первые 8 задач; «Показать ещё» расширяет список.

### Быстрые действия

Кнопка **«Открыть запись»** переключает внутренний раздел и фокусируется на исходной заявке, вкладе или публикации. **«Управлять кодом»** открывает «Паспорта» с поиском нужного ученика. **«Перейти к привязке»** открывает существующий механизм синхронизации ID.

**Ни одна кнопка Центра задач не подтверждает заявку, не публикует материал, не отзывает код и не выдаёт секретный код автоматически.** Обработка выполняется только в исходной карточке по дополнительному действию руководителя.

### Безопасность

- Источник: уже существующий owner-only `admin60Dashboard()`, который вызывает `requirePassportAdmin_()` до доступа к данным.
- Сервер собирает очередь только чтением Google Sheets. Никаких писем, триггеров или новых публичных методов.
- В очереди нет секретных кодов, их хэшей и контактных адресов отправителей. Имена учащихся доступны только владельцу внутри его закрытой панели.
- Не создаются новые листы, не изменяются настройки доступа и ученический EcoPassport. Старые работающие функции сохранены.
- Возвращается максимум 120 задач, с явной пометкой, если их больше; счётчики при этом считаются по всем строкам источника.
- Задачи обновляются вручную кнопкой или при обновлении страницы. Не выдавайте их за уведомления в режиме реального времени.

## Как установить

1. Откройте `Eco Club — Passport Admin` в Google Apps Script и сохраните резервные копии текущих `Код.gs` и `AdminPanel.html`.
2. Скачайте ZIP исходников из [GitHub](https://github.com/gulyantsdanil-oss/eco-club-m.auezov/archive/refs/heads/main.zip). Извлеките файлы и открывайте их **через Блокнот**, без автоперевода Яндекс Браузера.
3. Полностью замените `Код.gs` содержимым [passport-admin-server.gs](passport-admin-server.gs).
4. Полностью замените `AdminPanel.html` содержимым [passport-admin-panel.html](passport-admin-panel.html).
5. Сохраните оба файла. Существующие свойства `ECO_SOURCE_SPREADSHEET_ID`, `ECO_EVENTS_SPREADSHEET_ID`, `ECO_ADMIN_EMAIL` должны остаться без изменений.
6. Выберите **Начать развёртывание → Управление развёртываниями → изменить существующее развёртывание → Версия: Новая версия → Развернуть**.
7. Не меняйте защиту: **«Только я»**, выполнять от имени **пользователя, открывшего приложение**.
8. Откройте прежнюю закрытую ссылку `/exec`; обновите страницу. Значок должен показывать **ECO CLUB HUB 6.5 · PRIVATE**.

## Проверка перед работой

1. Главный экран: видны четыре счётчика Центра задач, фильтры и список задач.
2. «Срочные»: показывает только задачи критического или высокого приоритета. «Паспорта»: показывает задачи по доступу.
3. Выберите любую задачу (лучше задачу без необходимости изменения данных) → «Открыть запись». Должен открыться нужный внутренний раздел с найденной карточкой.
4. В разделе «Заявки» остаются фильтры «На рассмотрении / История / Все», в «Вклады» — фильтры статусов и классов.
5. В «Мероприятия» сохранены публикация, снятие и очистка тестов.
6. В «Паспорта» сохранены выдача и отзыв кодов, сроки и необязательные еженедельные уведомления.

После проверки рекомендуем сначала нажать **«Обновить задачи»** и сверить числа с действующими разделами. Для реальных заявок и мероприятий не нажимайте «Подтвердить» до проверки содержимого. Если интерфейс не изменился, проверьте, что вы развернули **«Новую версию»** (это не происходит автоматически после обновления GitHub).

## Результаты внутренних тестов

- Корректно собираются задачи по заявкам, ожидающим и непривязанным вкладам, модерации, зарегистрированным участникам без кода и скорому истечению срока.
- Критические задачи располагаются первыми.
- Проверены фильтрация списка, раскрытие первых 8 задач и переходы к разделам.
- В тестовых возвращаемых объектах отсутствуют SHA-хэши и email педагога.
- Несанкционированный аккаунт не может открыть `admin60Dashboard()`.
- Исходные таблицы и фото не изменялись при тестировании.
