**Статус:** внедрено непосредственно в существующую главную страницу GitHub Pages.
Ссылка: https://gulyantsdanil-oss.github.io/eco-club-m.auezov/#projects

## Что изменено

Файлы в GitHub:
- `index.html` — заменён только раздел с `id="projects"`. Заголовок, все 6 авторских проектов, RU/KZ тексты и иллюстрации сохранены; процесс «От идеи — к реальному результату» сохранён.

- `eco-earth-texture.svg` — самостоятельная векторная карта Земли (упрощённые географические контуры на основе общедоступного геодатасета Natural Earth); хранится в том же репозитории.

Никакие файлы EcoPassport, Google Apps Script, панели администратора, заявок или наград при этом изменении не затрагивались.

## Шесть направлений — исходные материалы сайта

1. Раздельный сбор отходов / Қалдықтарды бөлек жинау — `project-recycling.jpg`.
2. Зелёная школа / Жасыл мектеп — `project-green-school.jpg`.
3. Чистый десант / Таза десант — `project-cleanup.jpg`.
4. Эко-просвещение / Эко-ағарту — `project-education.jpg`.
5. Зелёный обмен / Жасыл алмасу — `project-exchange.jpg`.
6. Эко-патруль / Эко-патруль — `project-patrol.jpg`.

На большом экране проекты расположены в двух колонках по три карточки вокруг глобуса. При прокрутке внутри секции последовательно открываются 1–6 карточек; уже открытые остаются видимыми. Текст краткого описания ограничен тремя строками, полное описание можно открыть через «Подробнее о проекте».

На телефоне глобус расположен над активной карточкой. Прокрутка страницы, нажатия на точки, кнопки «Назад/Далее» и горизонтальный свайп по глобусу переключают шесть направлений.

Реализованы:
- эффект вращающейся Земли (реальная самодостаточная SVG-карта, анимированный фон внутри круглой сферы, 3D-подсветка и кольца орбиты);
- прокрутка **всей страницы**, а не блокировка колёсика — секция удерживается липким позиционированием на время шести шагов;
- физические кнопки и прогресс 01/06…06/06;
- интерактивная подробная карточка в модальном окне;
- поддержка РУС/ҚАЗ через текущий механизм `data-ru/data-kz`, без изменения языковых функций;
- клавиши стрелок на сфокусированном глобусе и доступное управление кнопками;
- режим `prefers-reduced-motion` без автоматического вращения;
- статический fallback: при недоступном JS остаются доступны все шесть карточек.

**Важно:** это реальный HTML/CSS/JS-элемент, а не статичная картинка из макета. Композиция вдохновлена утверждённым визуальным вариантом, но само вращение и открытие карточек программные.

## Проверка на сайте

1. Откройте https://gulyantsdanil-oss.github.io/eco-club-m.auezov/#projects . При необходимости сделайте `Ctrl+F5`, чтобы браузер взял свежие HTML, CSS и JS с GitHub Pages.
2. При входе в раздел появится глобус и первая карточка. Прокручивайте страницу вниз, проверяйте последовательное раскрытие всех 6 проектов.
3. Используйте стрелки, точки справа и нажатие на глобус.
4. Нажмите «Подробнее о проекте»: должны открыться иллюстрация и полное описание.
5. Проверьте переключение **РУС / ҚАЗ** на самой странице и при открытом диалоге.
6. На телефоне проверьте прокрутку и горизонтальный свайп по глобусу. Вертикальная прокрутка не должна блокироваться.
7. Проверьте переход ниже раздела к «Новости», а выше к «Результаты»; остальные разделы не менялись.
8. При необходимости проверьте системную настройку уменьшения анимации и отключённый JavaScript.

## Технические проверки

- Синтаксис JS в новом файле и в существующих inline-скриптах сайта.
- Все идентификаторы DOM в новом модуле существуют; дубликатов ID нет.
- Проверена корректность шести карточек, шести элементов навигации, шести кнопок подробного описания.
- В изолированной имитации DOM проверены: последовательное раскрытие по скроллу; переход на шестой проект; кнопка «Назад»; модальное окно и закрытие; изменение вида при переходе с десктопа на телефон; свайп на мобильном; исключение скрытых кнопок из tab-очереди.
- SVG-карта создана с 291 географическим контуром и хранится локально в проекте; внешние JavaScript-библиотеки не требуются.
- Публикация на GitHub прошла. Проверка визуального рендеринга в вашем браузере нужна отдельно после обновления GitHub Pages.
