# Eco Club HUB 6.8.1 — Новый печатный дизайн PDF-сертификатов

Изучен реальный сертификат `AWD-1720a7af-fe47-48df-9031-b2002c7a8f6b.pdf` (1 страница A4).
Выявленные особенности: аккуратные шрифты и правильные RU/KZ тексты, но нет обрамления и логотипа, много свободного места, некорректная русская форма `4 вклад`, слишком заметный идентификатор.

## Изменения, уже записанные в GitHub

Файлы:
- `passport-admin-server.gs` — новая функция формирования печатного PDF и защищённое обновление существующей награды;
- `passport-admin-panel.html` — версия 6.8.1, кнопка «Обновить оформление PDF» в реестре выданных наград.

Новый Google Docs → PDF генератор:
- одностраничный портретный A4, зелёная декоративная рамка, золотая акцентная полоска;
- фирменный логотип по публичной ссылке `eco-club-logo.png` из GitHub Pages, если доступен из Apps Script; безопасная текстовая замена при ошибке загрузки;
- крупный двуязычный заголовок, выделенное ФИО, результат, причина на русском и казахском;
- грамматически правильное `1 вклад / 2 вклада / 4 вклада / 5 вкладов`;
- место для настоящей подписи руководителя и печати; подпись/печать **не подделываются**;
- дата и регистрационный номер перенесены вниз малым шрифтом.

### Обновление уже выданного сертификата

**Не выдавайте награду повторно.** В HUB → «Награды» → «Реестр выданных наград» найдите действующий сертификат и нажмите **«Обновить оформление PDF»**. После подтверждения:
1. функция `admin681RefreshCertificate(awardId)` снова проверит, что вы — владелец и награда действующая;
2. сформирует новый частный PDF **с тем же номером награды и сохранённой датой первоначальной выдачи**;
3. заменит только ссылку PDF в существующей строке листа `Награды`, **без создания новой строки**;
4. после обновления ссылки перенесёт прежний файл PDF в корзину Google Drive;
5. в реестре нажмите «Скачать PDF», чтобы получить обновлённую версию.

Ранее **скачанные** копии PDF измениться не могут. При сбое создания новой версии старая ссылка в реестре остаётся действующей. Временные документы очищаются.

## Установка

1. Сохраните резервные копии текущих файлов Apps Script.
2. В существующем проекте **Eco Club — Passport Admin** замените `Код.gs` содержимым [passport-admin-server.gs](passport-admin-server.gs).
3. Замените `AdminPanel.html` содержимым [passport-admin-panel.html](passport-admin-panel.html).
4. Сохраните, отключив автоматический перевод кода в Яндекс Браузере.
5. «Начать развёртывание → Управление развёртываниями → карандаш → Новая версия → Развернуть».
6. Доступ оставить **«Только я»**, запуск **от имени пользователя, открывшего приложение**. Не меняйте свойства скрипта и не публикуйте закрытые файлы.
7. После обновления видно **ECO CLUB HUB 6.8.1 · PRIVATE**.

## Приёмочные проверки

1. Найдите прежний сертификат в разделе «Награды» и, если хотите заменить оформление, нажмите «Обновить оформление PDF».
2. Убедитесь, что число действующих наград **не изменилось**.
3. Скачайте PDF и проверьте 1 страницу A4; нет обрезанных заголовков; RU/KZ отображаются; корректное `4 вклада`.
4. Проверьте наличие рамки, полоски, места подписи, дату и номер `AWD-...`.
5. При наличии права на реальную печать проверьте масштабы 100%, печать на A4 и читаемость.
