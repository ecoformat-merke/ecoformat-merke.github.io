# HUB 6.8.3 — Фирменный графический сертификат А4 (альбомный)

Этот режим использует **готовый редактируемый шаблон Google Slides**, созданный из утверждённого изображения пользователя. Он сохраняет графическую декоративную рамку и фиксированный заголовок «СЕРТИФИКАТ», а 9 динамических текстовых полей заменяются данными из реестра наград.

## Однократная установка шаблона

1. Скачайте файл **Eco_Club_Premium_A4_Template.pptx** из чата ChatGPT.
2. Загрузите PPTX в **ваш Google Drive** (Новый → Загрузить файл).
3. Откройте его с помощью Google Презентаций и выберите **Файл → Сохранить как Google Презентации**. Используйте **именно новый нативный документ Google Slides**, а не оригинальный PPTX.
4. В адресе созданной презентации `https://docs.google.com/presentation/d/ID/edit` скопируйте **только ID** (между `/d/` и `/edit`).
5. В Google Apps Script проекте **Eco Club — Passport Admin** откройте Настройки проекта → Свойства скрипта и создайте свойство `ECO_HUB683_TEMPLATE_ID` со значением ID вашей презентации.
6. Замените `Код.gs` из [passport-admin-server.gs](passport-admin-server.gs), `AdminPanel.html` из [passport-admin-panel.html](passport-admin-panel.html), сохраните и обновите существующее развёртывание до **Новой версии**. Не отключайте проверку владельца и не делайте презентацию публичной.
7. Откройте **Награды → Реестр → Premium А4 · фирменный** у существующей действующей награды и скачайте PDF. Файл формируется из личной копии шаблона и остаётся закрытым.

**Обратите внимание:** графический шаблон намеренно содержит пустые поля подписи и печати. Реальные личные данные, дата и номер сертификата добавляются поверх декора динамически. Не выдавайте макет-превью за документ с действительным регистрационным номером: номера генерируются из реестра.

Без свойства `ECO_HUB683_TEMPLATE_ID` система сохраняет предыдущий работающий генератор 6.8.2. При указанном, но недоступном ID функция возвращает ошибку вместо незаметной подмены шаблона.

## Поля, заменяемые автоматически

`{{TITLE_RU}}`, `{{TITLE_KZ}}`, `{{STUDENT_NAME}}`, `{{CLASS_BILINGUAL}}`, `{{REASON_RU}}`, `{{REASON_KZ}}`, `{{METRIC}}`, `{{AWARD_ID}}`, `{{AWARD_DATE}}`.

Разделение графики и текста позволяет выпускать новые сертификаты без изменения художественного фона. Номер награды и первоначальная дата при переоформлении сохраняются, дополнительная строка в реестре не создаётся. После успешной замены ссылки старая PDF-копия перемещается в корзину.

**Проверки:** размер альбомного A4 исходной презентации — 841,89 × 595,28 pt; все девять маркеров присутствуют; новая функция закрыта проверкой владельца через существующие методы выдачи/переоформления. Реальный импорт в Google Slides, разрешения и PDF нужно подтвердить после настройки у владельца.
