# Eco Club HUB 6.8 — Награды и двуязычные PDF-сертификаты

**Готово в GitHub; требуется установить новую версию в действующем закрытом приложении.** Реальные награды пока не выдавались, реальные вклады и коды EcoPassport не изменялись.

## Важный итог проверки таблицы
В основной таблице `Eco Club — Заявки на вступление` обнаружены готовые листы:
- `Награды` — 18 столбцов A–R, заголовки заполнены.
- `Шаблоны наград` — 12 столбцов A–L, три активных шаблона размещены по строкам 2–4.

В некоторых заголовках скрыт начальный символ табуляции. Код 6.8 **автоматически удаляет пробелы/табуляцию при сверке заголовков**, поэтому пользователю не нужно переписывать таблицу. Данные в таблице ни при проверке, ни при разработке не изменялись.

## Что добавлено

### Новый раздел «Награды»
В верхнем меню есть вкладка «Награды», в ней:
1. Счётчики участников, активных шаблонов, кандидатов и действующих наград.
2. Кандидаты на награждение на основании **реальных подтверждённых вкладов**, поиска по ФИО/классу/награде и ручная кнопка **«Выдать PDF-награду»**.
3. Реестр наград, повторное скачивание, фильтры действующих/отозванных и кнопка «Отозвать награду» с двойным подтверждением.
4. Список используемых шаблонов и текущих условий получения.

### Награды и пороги
- `FIRST_CONTRIBUTION`: хотя бы **1 подтверждённый вклад**.
- `PAPER_5KG`: суммарно **не менее 5 кг макулатуры**.
- `CAPS_100`: суммарно **не менее 100 крышек**.

Пороги берутся из листа «Шаблоны наград», а не жёстко из пользовательского интерфейса. Код распознаёт только перечисленные три типа правил; новые правила требуют отдельного внедрения/проверки.

Учёт ведётся по постоянному ID EcoPassport. Вклады без ID используются по совпадению ФИО и класса только если такое совпадение **однозначно**. Отклонённые, тестовые и некорректные вклады не учитываются.

### Выпуск PDF
Награда создаётся только после подтверждения руководителем:
1. Сервер проверяет администратора, существование активного ученика и активного шаблона, достижение порога и отсутствие ранее выданной действующей награды **того же шаблона**.
2. Создаёт временный Google Docs документ, форматирует двуязычный сертификат на русском и казахском с названием, ФИО, классом, подтверждённым результатом, датой, идентификатором награды и местом для подписи.
3. Конвертирует документ в PDF и кладёт его в **закрытую** папку `Eco Club — Закрытые сертификаты` в Google Drive.
4. Переносит временный документ в корзину. Записывает выдачу в лист **«Награды»** A–R, сохраняя ссылку на PDF, дату и email владельца.
5. Из кабинета PDF скачивается только после серверной проверки владельца; прямой доступ к файлу другим аккаунтам не предоставляется.

Папка создаётся автоматически при первом выпуске, её ID сохраняется в Script Properties под `ECO_HUB68_AWARDS_FOLDER_ID`. Вручную создавать свойство **не нужно**.

**Текущая версия использует типографическое оформление без вставки графического файла логотипа.** Фирменный логотип, факсимиле и высокодетализированный печатный дизайн можно добавить отдельно после проверки первой PDF-выгрузки. Подпись руководителя **не подделывается**: оставлено поле для подписи от руки. Функция выдачи оформляет реальное школьное награждение только по ручному действию.

### История и отзыв
Повторная выдача активной награды одному ученику по одному и тому же шаблону блокируется. В случае отзыва статус меняется на `revoked`, но запись и файл остаются для внутреннего аудита. Новая выдача после отзыва допускается по явному решению руководителя.

Важно: отзыв **не может уничтожить уже скачанные кем-либо копии**, поэтому распространять документы следует только согласованным адресатам.

## Установка

1. Откройте **Eco Club — Passport Admin** в Google Apps Script и сохраните резервные копии `Код.gs` и `AdminPanel.html`.
2. Откройте GitHub ZIP: https://github.com/gulyantsdanil-oss/eco-club-m.auezov/archive/refs/heads/main.zip .
3. Через Блокнот Windows скопируйте содержимое `passport-admin-server.gs` в **`Код.gs`**.
4. Через Блокнот скопируйте содержимое `passport-admin-panel.html` в **`AdminPanel.html`**.
5. Сохраните оба файла; отключите автоматический перевод Яндекс Браузера.
6. Сохраняйте прежние свойства `ECO_SOURCE_SPREADSHEET_ID`, `ECO_EVENTS_SPREADSHEET_ID`, `ECO_ADMIN_EMAIL`. Свойства наград вручную не добавляйте.
7. **Начать развёртывание → Управление развёртываниями → Изменить действующее → Версия: Новая версия → Развернуть.**
8. Безопасность сохранить: **Кому доступно: Только я**, выполнение **от имени пользователя, открывшего приложение**.
9. Обновите прежнюю ссылку `/exec`. Новая версия: **ECO CLUB HUB 6.8 · PRIVATE**.

Не изменяйте публичный GitHub Pages или отдельный ученический проект EcoPassport.

## Приёмочные проверки

**Сначала только чтение:**
1. Откройте «Награды», убедитесь в трёх шаблонах и списке подходящих кандидатов. Наличие кандидата не означает выдачу!
2. Проверьте поиск по ФИО и фильтр реестра.
3. Если готово выдать реальную награду — выберите ученика с подтверждённым достижением, проверьте ФИО/класс, нажмите «Выдать PDF-награду» и подтвердите.
4. Проверьте запись `issued` на листе «Награды», убедитесь, что появилась ссылка на закрытый PDF.
5. Скачайте PDF из реестра и проверьте на экране/печати: русский и казахский текст, корректность имени, номера и страницы. Не выкладывайте файл публично.

**Возможные разрешения:** Google может запросить дополнительные OAuth-права на Google Docs и Drive при первом выпуске PDF. Эти разрешения нужны для создания документа и хранения закрытого файла. Не меняйте доступ веб-приложения на «Все» ради авторизации.

**Ограничения:** шаблоны в текущем MVP поддерживают только три заявленных правила. Награды пока не публикуются автоматически в личном кабинете ученика EcoPassport; интеграция в публичный/ученический интерфейс возможна отдельным безопасным обновлением. Функции проверены в изолированной имитации Apps Script, но реальный вид PDF и работу разрешений следует подтвердить после установки.
