# Eco Club / EcoPassport 6.9 — «Мои сертификаты»

**Статус:** исходники сохранены в GitHub. Рабочая ученическая Google Apps Script публикация начнёт использовать 6.9 только после обновления её существующего развёртывания. Административный проект **не** требует обновления для этого этапа.

## Файлы

- [passport-server.gs](passport-server.gs) — новый ученический сервер. Установка: `Код.gs` в проекте **Eco Club — Private Passport**.
- [passport-portal.html](passport-portal.html) — новый закрытый ученический интерфейс. Установка: HTML-файл **`PassportPortal`** в том же проекте.

**Не вставляйте эти два файла в административный проект `Eco Club — Passport Admin`.** В административном проекте остаются прежние права и функции HUB 6.8.3.

## Как работает

После входа по индивидуальному коду `getMyPassport(code)` проверяет:
1. Корректность 64-символьного кода и совпадение SHA-256 с закрытым листом `Паспорт — доступ`.
2. Активность кода, срок его действия (когда указан).
3. Указанный в H постоянный ID и активную запись ID в `Паспорт — участники`.
4. По ID из столбца C листа `Награды` извлекает **только** записи со статусом `issued` (столбец N), существующим зарегистрированным PDF (столбец M) и уникальным `award_id`.

Возвращается только ограниченный набор данных собственной награды: ID, RU/KZ название и причина, значение достижения, единица и дата выдачи. URL из Google Drive и личные сведения других учеников не возвращаются.

Для скачивания PDF браузер использует отдельный временный 64-символьный случайный токен (не исходный персональный код). Токен создаётся **только после успешного входа** и хранится в ScriptCache до 15 минут. При каждой загрузке `downloadMyCertificate(token, awardId)` заново проверяет активность кода и ID в реестре, принадлежность награды этому участнику и статус `issued`, после чего возвращает приватный PDF в base64. Выдаётся файл размером до 4 МиБ. Токен не попадает в адресную строку, файлы не публикуются через общедоступный доступ Drive.

При истечении 15-минутного разрешения ученик должен **закрыть и заново открыть паспорт** по личному коду. Если награда отозвана администратором, скачивание немедленно блокируется.

### Два вида наград

- **Мои экодостижения / Менің эко жетістіктерім** — прежние автоматически рассчитанные значки: 1, 3 вклада, 5/10 кг, 100 крышек.
- **Мои сертификаты / Менің сертификаттарым** — только официально выданные и не отозванные награды из таблицы `Награды`; есть кнопка `Скачать сертификат PDF / PDF сертификатты жүктеу`.

Кодам старого формата **без постоянного ID** сертификаты не показываются. Для них предлагается получить новый код в администрации; ранее работающие показатели и значки остаются доступными.

## Установка в существующем Apps Script

1. Откройте Google Apps Script проект **Eco Club — Private Passport** (именно ученический, НЕ `Passport Admin`).
2. Сохраните резервные копии текущих файлов `Код.gs` и `PassportPortal.html`.
3. Скачайте архив исходников: https://github.com/gulyantsdanil-oss/eco-club-m.auezov/archive/refs/heads/main.zip .
4. Через **Блокнот Windows** откройте `passport-server.gs` и полностью замените содержимое `Код.gs`.
5. Откройте `passport-portal.html` и полностью замените содержимое HTML-файла `PassportPortal`.
6. Отключите автоматический перевод Яндекс Браузера при копировании кода (ранее он повреждал JS).
7. Нажмите `Ctrl+S`. **Не меняйте** Script Properties `ECO_SOURCE_SPREADSHEET_ID`.
8. Откройте **Развернуть → Управление развёртываниями → карандаш у существующего развёртывания → Новая версия → Развернуть**.
9. В отличие от админки, ученическое приложение должно продолжать выполняться **от имени владельца** и оставаться доступным только **пользователям с Google-аккаунтом**. **Не** включайте анонимный публичный доступ.
10. Обновите прежний ученический URL `/exec`. В левом верхнем углу должно быть **`ECO CLUB / ECOPASSPORT 6.9`**.

Для чтения закрытых PDF сервер может потребовать расширить OAuth-разрешения на Google Drive. Авторизацию подтверждает **владелец проекта**, не нужно давать детям доступ к административной таблице или папке. Если PDF не скачивается, проверьте **Выполнения** Apps Script и выданные разрешения; **не делайте PDF общедоступными** ради устранения ошибки.

## Проверка после установки

1. С помощью действующего индивидуального кода одного участника откройте его EcoPassport. **Не отправляйте личный код в чат.**
2. Убедитесь, что старые результаты, уровень, вклад и значки не изменились.
3. Появилась отдельная секция **«Мои сертификаты»** с собственными выданными наградами, если они есть.
4. Попробуйте переключить **РУС / ҚАЗ**: тексты названий и причин должны измениться.
5. Нажмите **«Скачать сертификат PDF»**, дождитесь сообщения о готовности и нажмите ссылку для сохранения.
6. Проверьте альбомный А4 и фирменный дизайн. Дата и идентификатор должны совпасть с реестром.
7. Откройте паспорт другого ученика, не получавшего эту награду. Чужой PDF появляться не должен.
8. Для проверок отзыва и истечения доступа не меняйте реальные коды детей ради теста; соответствующие сценарии проверены на моделируемых данных.
9. Проверьте отображение на телефоне.

## Проверки разработки

- Проверена синтаксическая корректность .gs и JavaScript в HTML.
- На изолированных фиктивных данных подтверждено: один ученик не видит чужой или отозванный сертификат, свой PDF получает только с правильным токеном, за истекшим/отозванным кодом доступ запрещён, деактивированный ID блокируется, чужие файлы Drive не открываются.
- Проверены русское и казахское отображение, готовая ссылка PDF, очистка временного URL при выходе из паспорта.
- Чтение реального закрытого листа `Награды` подтвердило **две действующие награды**, обе с валидными постоянными ID, связанными с активными участниками/доступами, и корректными приватными Drive URL. **Реальные награды и коды не изменены.**
- Фактическую работу Google Apps Script и выдачу PDF в ученическом интерфейсе ещё необходимо подтвердить после развёртывания.

## Ограничения и безопасность

Индивидуальный код является ключом доступа: **любое лицо, которому ученик передаст действительный код, сможет увидеть его личный паспорт**. Требование входа через Google не делает аккаунт пользователя подтверждённым владельцем кода. Не распространяйте коды, скриншоты паспортов и именные PDF без согласия и соблюдения правил школы по персональным данным учащихся.

Весь доступ к документам реализован в **закрытом Apps Script**, а не на публичном GitHub Pages. Не размещайте идентификаторы хэшей, открытые коды доступа или сам реестр наград в репозитории.
